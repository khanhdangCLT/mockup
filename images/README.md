# Nhật ký thay đổi ảnh mockup Dorco WMS

File này chỉ liệt kê ảnh nào có thay đổi, không kèm mô tả.

- **Mới**: ảnh mới thêm vào thư mục, chưa có trên trang.
- **Đã sửa**: ảnh đã có trên trang, file ảnh đã được sửa xong, chỉ cần thay mới ảnh.

Quy ước thư mục: mỗi mục một thư mục (01-master-data, 02-quy-trinh-mua…), trùng tên file trang trong pages/. Trong mỗi thư mục, tên ảnh là số (1.png, 2.png...). Cột "Ảnh" ghi kèm thư mục.
